## Version baseline

Checked on **20 October 2026**. Java 26 was released on 17 March 2026 and Java 27 on 15 September 2026. Java 27 is GA, not just an early-access build. Java 25 is the current LTS line on this timeline. Release-specific features in these notes distinguish finalized features, preview features, and HotSpot implementation details.

Sources: [JDK 26 release notes](https://www.oracle.com/java/technologies/javase/26-relnote-issues.html), [JDK 27 release notes](https://www.oracle.com/java/technologies/javase/27all-relnotes.html), [dev.java](https://dev.java/learn/).

## Suggested study order

1. Language basics → OOP → generics.
2. Collections → lambdas/streams.
3. Memory model/GC → concurrency.
4. Answer the true/false questions without looking at the explanations, then explain aloud why each false statement is false.
5. For implementation details (for example HashMap bucket thresholds), learn the behavior and the caveat: implementation details are not necessarily public API contracts.
